# 이름 물고기 뜨개 인형 (fish-plush-knit)

이름을 넣으면 그 이름으로 물고기를 그리고, 실 한 가닥으로 앞·뒤판을 떠서 감침질하고 솜을 넣은 복실복실한 3D 뜨개 인형을 바닷속에서 보여 주는 웹페이지입니다. 같은 이름은 항상 같은 물고기가 나오고, 그 인형을 실제로 뜰 수 있는 뜨개 도안도 함께 만듭니다.

빌드 도구나 서버 없이 `index.html` 한 파일로 동작하는 정적 사이트입니다.

## 할 수 있는 것

- **이름 → 물고기**: fishdraw가 이름을 시드로 물고기 선화를 그립니다. 라틴어 학명 무작위 생성도 됩니다.
- **뜨기 과정**: 앞판 뜨기 → 뒤판 뜨기 → 맞대고 꿰매기 → 솜 넣기 → 안전눈 달기. 진행 슬라이더, 속도, 바로 완성.
- **실 재질**: 복실 퍼얀, 모헤어, 셔닐 벨벳, 부클레, 울, 면사. 털 길이·밀도·처짐, 실 굵기, 광택, 울퉁불퉁함 조절.
- **배경**: 바닷속(빛줄기, 물빛 일렁임, 모래 바닥, 부유물) 또는 스튜디오.
- **보기**: 휠·핀치 확대, 재질 가까이 보기, 전체 보기, 완성 후 자동 회전.
- **색**: 이름에서 고른 3색(몸통·무늬·지느러미), 직접 바꾸기 가능.
- **뜨개 도안**: 차트(기호·단 번호·안전눈 자리), 조각별 단별 설명, 완성 크기, 게이지, 바늘, 색별 실 사용량, 부자재, 조립 순서, 글 도안 복사.

## 로컬에서 보기

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

인터넷 연결이 필요합니다(three.js는 jsDelivr, 글꼴은 Google Fonts에서 불러옵니다).

## 배포

정적 파일이라 저장소 루트를 그대로 올리면 됩니다.

- **GitHub Pages**: Settings → Pages에서 Source를 `Deploy from a branch`, 브랜치 `main` / 폴더 `/ (root)`. `.nojekyll`이 들어 있습니다. 비공개 저장소에서 Pages를 쓰려면 유료 플랜이 필요합니다.
- **Cloudflare Pages / Netlify / Vercel**: 빌드 명령 없음, 출력 폴더는 루트(`/`).
- **일반 웹 서버(Synology Web Station 등)**: 파일을 웹 루트에 복사.

## 구조

```
index.html                     배포되는 페이지 (빌드 결과물, 직접 수정하지 말 것)
src/fish-plush/
  page.template.html           원본: UI, 실 시뮬레이션, 인형 조립, 재질 셰이더, 바닷속 배경, 도안 생성기
  fishdraw.vendored.js         fishdraw 원본 + 눈 위치 노출, 이름별 시드 고정 수정
tools/build.py                 src → index.html 빌드
NOTICE.md                      서드파티 출처와 라이선스
```

수정은 `src/fish-plush/page.template.html`에서 하고 빌드합니다.

```bash
python3 tools/build.py
```

## 만드는 방식

- **실**: PyElastica의 코세라 막대(Cosserat rod) 이산화(노드 + 요소)를 브라우저용으로 단순화했습니다. 노드는 Verlet 입자, 신장은 요소 길이 제약, 굽힘은 이웃 노드 간 제약이고 비틀림은 생략했습니다. PyElastica 코드를 그대로 실행하거나 옮겨 온 것은 아닙니다.
- **실루엣과 배색**: 선화를 칠해 실루엣을 만들고, 선이 촘촘한 곳은 무늬색, 얇은 부분은 지느러미색 코로 나눕니다.
- **인형**: 실루엣 가장자리까지의 거리로 솜 부풀림을 정하고, 가장자리 코는 납작하게 두어 앞·뒤판이 맞닿게 합니다. 외곽선을 따라 감침질 실을 감아 두 판을 잇습니다. 털은 실 표면 위에 겹겹이 쌓은 셸 셰이더입니다.
- **도안 규칙**: 차트는 오른쪽 아래에서 시작, 홀수 단은 겉면(오른쪽→왼쪽), 짝수 단은 안면(왼쪽→오른쪽). 여러 코 코막음은 단 시작에서만 하도록 형태를 보정하고, 같은 보정을 3D 인형에도 적용해 도안과 인형 모양이 같습니다. 배색은 인타샤, 갈라지는 부분은 조각별로 뜨고 홀더로 넘깁니다.
